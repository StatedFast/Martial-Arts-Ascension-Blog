# 2026-10-23

## 代码 Review（只读，未改动任何代码）

对 spring-ai-demo（Spring Boot 3.4 + MyBatis-Plus + JWT + Spring AI 博客系统）做了性能与安全隐患审查，结论要点：

- 安全高危：changePassword/updateProfile 用 @RequestParam 传明文密码（进 URL 访问日志）；/api/user/profile 直接返回 User 实体（泄露 BCrypt 哈希）；默认 JWT 密钥与 DB 密码硬编码在 application.properties；种子账号 admin/123456 + DataInitializer 启动时把所有非 BCrypt 密码重置为 123456；登出/改密只吊销当前 access token，refresh token 与其他设备 token 仍有效；RateLimitInterceptor 计数永不重置导致永久封禁，@RateLimit 注解无切面实现；article.html 评论 replyTo 的 onclick 拼接 nickname（escapeHtml 不转义引号）造成存储型 XSS。
- 性能高危：LocalCacheService 无容量上限/无过期清理线程，文章列表缓存 key 含用户可控 keyword（可被刷爆内存）；list 接口 size、hotArticles limit 无上限；评论与热门文章 N+1；getArchiveStats 全量加载 LONGTEXT；@Async 自调用失效；keys() 全表扫描；SQL 缺 (status,is_top,create_time) 复合索引。
- 架构性：Redis 已引入但缓存/黑名单/限流仍是内存实现，多实例部署失效；ChatMemory 按 conversationId 无界增长。

后续如需落地修复，按「安全 → 缓存层 → SQL/索引」顺序推进。
